# Face Color Match for Photoshop

Face Color Match автоматически приводит цвет и тон кожи на фотографии к заранее сохранённому эталону.

Скрипт находит лицо, измеряет кожу в нескольких тональных диапазонах, сравнивает её с выбранным пресетом и создаёт обычные редактируемые корректирующие слои Photoshop.

Коррекция не заменяет изображение и не использует генеративные модели.

---

## Требования

- **Windows 10 / 11, 64-bit**
- современная настольная версия **Adobe Photoshop** с поддержкой JSX / ExtendScript
- **Python 3.11–3.14**

Рекомендуется устанавливать Python с python.org вместе с **Python Launcher for Windows (`py`)**.

### Цветовое пространство

Face Color Match рассчитан на **RGB-документы в sRGB IEC61966-2.1**.

Перед созданием эталона и перед применением коррекции убедитесь, что документ уже преобразован в sRGB:

```text
Edit → Convert to Profile → sRGB IEC61966-2.1
```

Используйте именно **Convert to Profile**, а не Assign Profile.

## Установка

1. Распакуйте архив Face Color Match.
2. Запустите `install.bat` и дождитесь успешного завершения.
3. Полностью закройте Photoshop.
4. Скопируйте в папку:

```text
Photoshop\Presets\Scripts\
```

следующие элементы:

```text
Face Color Match.jsx
lib\
```

В результате должно получиться примерно так:

```text
Photoshop\Presets\Scripts\
├─ Face Color Match.jsx
└─ lib\
   ├─ face-color-api.pyw
   └─ models\
```

`install.bat` в папку Photoshop копировать не нужно.

После этого запустите Photoshop заново. Скрипт появится в меню:

```text
File → Scripts → Face Color Match
```

Отдельно запускать Python-сервис не требуется.

## Быстрый старт

### Создать эталон

1. Откройте фотографию с подходящим цветом кожи.
2. Запустите **Face Color Match**.
3. Нажмите `+`.
4. Введите имя пресета.

Для более устойчивого эталона можно добавить несколько подходящих фотографий через обновление пресета и команду **Добавить и усреднить**.

### Применить коррекцию

1. Откройте фотографию, которую нужно привести к эталону.
2. Запустите **Face Color Match**.
3. Выберите пресет.
4. При необходимости настройте параметры.
5. Нажмите **Применить**.

Скрипт создаст отдельную группу корректирующих слоёв.

---

## Выбор лица

### Основное лицо

Подходит для обычного портрета. При выборе учитываются размер лица и его близость к центру кадра.

### Центральные лица (среднее)

Подходит для групповых фотографий. Скрипт выбирает до трёх подходящих лиц, ближайших к центру кадра, и усредняет их измерения кожи.

Этот же режим можно использовать при создании и обновлении эталона.

---

## Основные параметры

### Сила

```text
0–100%
```

Это opacity всей созданной группы.

```text
100% — полный рассчитанный эффект
50%  — половина видимого эффекта
```

Показанный ΔE относится к рассчитанной коррекции при силе 100%.

### Тени / света

```text
-100 … 0 … +100
```

```text
влево  → больший приоритет теням
0      → Auto
вправо → больший приоритет светам
```

Этот параметр влияет только на этап **Tone** и меняет распределение тоновой коррекции между тенями и светами. Он не меняет White Balance напрямую и не задаёт направление осветления или затемнения — направление всегда определяется эталоном.

Если этап Tone не даёт полезного и безопасного улучшения, он может не создаваться. В таком случае изменение этого ползунка будет мало заметно или не повлияет на результат.

Для обычной работы рекомендуется оставить `0`.

### Точность / защита

```text
-100 … 0 … +100
```

```text
Точность → допускает более активную подгонку
0        → Auto
Защита   → делает коррекцию осторожнее
```

В сторону **Точность** алгоритм получает больше свободы чтобы добиться меньших цветовых различий с эталоном.

В сторону **Защита** усиливаются ограничения на силу и безопасность коррекции. Если вариант Auto уже проходит более строгие ограничения, результат при Safety может остаться таким же.

Для большинства фотографий рекомендуется `0 — Auto`.

### Защита нейтралей

```text
0–100%
```

Защищает серые и белые объекты от паразитного оттенка, который иногда может появляться после глобального **White Balance**.

```text
0%   — защита выключена
100% — максимальная безопасная защита
```

При значении выше `0%` скрипт может создать дополнительный слой **Neutral Protect**. Сам LUT рассчитывается для максимальной безопасной нейтрализации, а положение ползунка управляет opacity этого слоя, поэтому сила воздействия меняется линейно.

Neutral Protect не заменяет White Balance: он частично отменяет его цветовой сдвиг только вблизи нейтральных оттенков. Цветные области и кожа по возможности сохраняют рассчитанную коррекцию. Если White Balance не создаётся, Neutral Protect также не нужен.

Для обычной работы рекомендуется оставить `0%` и увеличивать защиту только если серые или белые объекты получают заметный оттенок.

## Что создаётся в Photoshop

Коррекция может включать до четырёх этапов:

```text
White Balance
Neutral Protect
Tone
Skin Match
```

Создаются только нужные этапы. **Neutral Protect** появляется только при включённой защите нейтралей и наличии White Balance.

### White Balance

Исправляет общий цветовой сдвиг изображения с помощью Curves.

### Neutral Protect

Дополнительный **Color Lookup LUT**, который ослабляет паразитный оттенок White Balance на серых и белых объектах. В имени слоя показывается фактическое изменение ΔE с учётом его opacity.

### Tone

Корректирует светлоту кожи плавной Composite RGB Curve.

### Skin Match

Выполняет остаточную подгонку цвета кожи через **33×33×33 Color Lookup LUT**.

Все созданные слои объединяются в одну группу и остаются обычными редактируемыми слоями Photoshop.

---

## ΔE

Face Color Match использует **CIEDE2000 ΔE**.

Например:

```text
ΔE 7.1→4.4 — Face Color Match — preset
```

Чем меньше итоговое значение, тем ближе измеренный цвет кожи к эталону.

Названия отдельных слоёв могут показывать вклад каждого этапа:

```text
White Balance ΔE 7.1→6.9
Neutral Protect ΔE 6.9→7.0
Tone ΔE 7.0→5.8 · ΔL* 8.1→6.7
Skin Match ΔE 5.8→4.4
```

Neutral Protect предназначен для сохранения нейтральных объектов, поэтому он не обязан уменьшать ΔE кожи и иногда может немного его увеличить. `ΔL*` у Tone относится только к светлоте и поэтому не совпадает с общим ΔE.

## Пресеты

Кнопка `+` создаёт новый эталон из текущего документа.

Кнопка `↻` позволяет:

- **Добавить и усреднить** — добавить текущую фотографию к существующему эталону;
- **Заменить** — полностью заменить эталон текущими измерениями.

Кнопка `x` удаляет выбранный пресет после подтверждения.

Хороший эталон желательно выбирать на фотографии, где:

- кожа нормально экспонирована;
- нет выбитых светов;
- лицо достаточно крупное;
- нет сильного локального цветного рефлекса;
- освещение лица достаточно равномерное.

Для важных пресетов полезно усреднить несколько согласованных фотографий.

---

## Настройки

Под кнопкой с шестерёнкой доступны:

- **Папка пресетов**;
- **Размер анализа, px**;
- **Пропускать изображение, если лицо не найдено**;
- **Имя слоя**.

Размер анализа по умолчанию — **1400 px**. Для большинства портретов этого достаточно. Если лицо очень маленькое в кадре, значение можно увеличить.

Опция **Пропускать изображение, если лицо не найдено** удобна при пакетной обработке через Photoshop Actions.

---

## Photoshop Actions

Face Color Match поддерживает запись и воспроизведение через Photoshop Actions.

В Action сохраняются основные параметры коррекции и выбранный пресет. Если диалог Action включён, параметры можно изменить перед применением. Если выключен — используются записанные значения.

Для корректной работы скрипт должен быть установлен в `Photoshop\Presets\Scripts`.

---

## Важные особенности

- исходный документ не перезаписывается;
- анализ выполняется по временной JPEG-копии;
- после временного изменения размера документ возвращается к исходному History State и положению холста;
- временные файлы автоматически удаляются;
- коррекция добавляется как одна операция History;
- Python-сервис запускается автоматически и выключается после 30 минут бездействия.

## Если что-то не работает

### Скрипт не появился в меню

Проверьте, что `Face Color Match.jsx` и папка `lib` находятся именно в:

```text
Photoshop\Presets\Scripts\
```

После копирования полностью перезапустите Photoshop.

### Скрипт не запускается

1. Убедитесь, что установлен Python 3.11–3.14.
2. Снова запустите `install.bat` в распакованной папке программы.
3. После успешной установки заново скопируйте `Face Color Match.jsx` и папку `lib` в Photoshop.
4. Перезапустите Photoshop.

### Лицо не найдено

- увеличьте **Размер анализа**;
- убедитесь, что лицо достаточно крупное и не сильно перекрыто;
- для группового фото попробуйте **Центральные лица (среднее)**.

### Результат слишком слабый

- убедитесь, что **Сила = 100%**;
- немного сдвиньте **Точность / защита** в сторону Точность.

### Результат слишком сильный

- сдвиньте **Точность / защита** в сторону Защита;
- либо уменьшите **Силу** группы.

### Цвет выглядит неправильно

Проверьте качество эталона и убедитесь, что и эталон, и текущий документ находятся в **sRGB IEC61966-2.1**.

Если после коррекции серые или белые объекты получают паразитный оттенок, постепенно увеличьте **Защиту нейтралей**.
