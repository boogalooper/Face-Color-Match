# Face Color Match for Photoshop

Face Color Match помогает автоматически привести цвет и тон кожи на фотографии к заранее сохранённому эталону.

Вы открываете фотографию в Photoshop, выбираете пресет с нужным эталоном кожи и запускаете коррекцию. Скрипт находит лицо, измеряет кожу в нескольких зонах и тональных диапазонах, сравнивает её с эталоном и создаёт обычные редактируемые корректирующие слои Photoshop.

Коррекция не заменяет изображение и не использует генеративные модели. На выходе остаются **Curves + один Color Lookup LUT**, объединённые в одну группу.

---

# Что умеет программа

- автоматически находит лицо на фотографии;
- поддерживает обычные портреты и групповые фотографии;
- сравнивает цвет кожи в тенях, средних тонах и светах;
- автоматически корректирует баланс белого, светлоту, насыщенность и оттенок кожи;
- строит плавные коррекции без ломаных кривых;
- использует один итоговый **33×33×33 Skin Match LUT**;
- автоматически ослабляет или отклоняет небезопасные варианты коррекции;
- поддерживает многокадровые эталоны с усреднением нескольких фотографий;
- показывает ΔE до и после коррекции;
- поддерживает Photoshop Actions;
- автоматически запускает локальный Python-сервис и выключает его после 30 минут бездействия.

# Требования

## Windows

Текущая версия предназначена для **64-битной Windows 10 / 11**.

## Adobe Photoshop

Рекомендуется использовать современную настольную версию Adobe Photoshop с поддержкой JSX / ExtendScript.

## Python

Face Color Match использует системный Python.

Поддерживаются:

```text
Python 3.11
Python 3.12
Python 3.13
Python 3.14
```

Рекомендуется устанавливать Python с официального python.org вместе с **Python Launcher for Windows (`py`)**.

---

# Обязательное требование: sRGB

**Face Color Match рассчитан только на RGB-документы в профиле sRGB IEC61966-2.1.**

Перед созданием эталона и перед применением коррекции документ должен уже находиться в sRGB.

Если документ находится в другом RGB-профиле, используйте:

```text
Edit → Convert to Profile → sRGB IEC61966-2.1
```

Нужно именно **Convert to Profile**.

`Assign Profile` не является эквивалентной операцией.

# Установка и первый запуск

В комплекте используется один установщик:

```text
install.bat
```

Соблюдайте порядок установки.

## 1. Установите Python

Установите любую поддерживаемую версию Python 3.11–3.14.

Если Python уже установлен, переходите к следующему шагу.

## 2. Запустите install.bat

Запустите `install.bat` **в распакованной папке Face Color Match** и дождитесь успешного завершения.

Пользователю не требуется вручную устанавливать отдельные библиотеки.

Важно: **сначала выполните `install.bat`, и только после этого копируйте папку `lib` в Photoshop**.

## 3. Закройте Photoshop

Если Photoshop открыт, полностью закройте его.

## 4. Скопируйте скрипт в Photoshop

После успешной установки скопируйте в:

```text
Photoshop\Presets\Scripts
```

два элемента:

```text
Face Color Match.jsx
lib\
```

Должна получиться структура:

```text
Adobe Photoshop ...
└─ Presets
   └─ Scripts
      ├─ Face Color Match.jsx
      └─ lib
         ├─ face-color-api.pyw
         └─ models
```

Обычный путь выглядит примерно так:

```text
C:\Program Files\Adobe\Adobe Photoshop <версия>\Presets\Scripts\
```

`install.bat` копировать в Photoshop не нужно.

## 5. Запустите Photoshop заново

Face Color Match должен появиться в меню:

```text
File → Scripts → Face Color Match
```

Запускайте установленную копию именно оттуда.

**Face Color Match.jsx должен находиться в папке Scripts Photoshop.** Это необходимо для корректной работы постоянного Event ID и Photoshop Actions.

Отдельно запускать Python-сервис не требуется.

# Быстрый старт

## Создание первого эталона

1. Откройте фотографию с подходящим цветом кожи.
2. Запустите **Face Color Match**.
3. Нажмите `+`.
4. Введите имя пресета.

После измерения пресет появится в списке.

## Применение коррекции

1. Откройте фотографию, которую нужно привести к эталону.
2. Запустите **Face Color Match**.
3. Выберите нужный пресет.
4. При необходимости настройте параметры.
5. Нажмите **Применить**.

Скрипт создаст отдельную группу корректирующих слоёв.

# Выбор лица

Доступны два режима.

## Основное лицо

Подходит для обычного портрета.

Скрипт учитывает:

- размер лица;
- близость лица к центру кадра.

## Центральные лица (среднее)

Подходит для групповых фотографий.

Скрипт:

- находит все лица;
- выбирает до **3 лиц**, ближайших к центру кадра;
- отбрасывает слишком дальние и слишком маленькие лица;
- усредняет их измерения кожи.

Этот режим помогает ориентироваться на центральную часть группы, а не на случайно более крупное лицо слева или справа.

Тот же режим можно использовать при создании и обновлении эталона.

# Пресеты

## Где хранятся

По умолчанию:

```text
app.preferencesFolder\Face Color Match Presets
```

Папку можно изменить в настройках.

## Создание

Кнопка:

```text
+
```

создаёт новый эталон из текущего документа.

## Обновление

Кнопка:

```text
↻
```

предлагает два варианта:

```text
Добавить и усреднить
Заменить
```

### Добавить и усреднить

Текущая фотография добавляется к существующему эталону.

Измерения усредняются в Lab отдельно по зонам лица и тональным диапазонам. Это уменьшает влияние случайного рефлекса, освещения или особенностей одного кадра.

### Заменить

Старый эталон полностью заменяется измерениями текущей фотографии.

# Как выбрать хороший эталон

Лучше использовать фотографию, где:

- кожа нормально экспонирована;
- нет выбитых светов;
- нет сильного цветного рефлекса только с одной стороны лица;
- лицо достаточно крупное;
- обе стороны лица освещены достаточно согласованно.

Если эталон выглядит нестабильным, Face Color Match покажет предупреждение, но не запретит его сохранить.

Для важного пресета полезно добавить несколько согласованных фотографий через **Добавить и усреднить**.

# Главное окно

## Пресет

Выбирает эталон, к которому будет приводиться кожа.

## Лицо

```text
Основное лицо
Центральные лица (среднее)
```

Выбирает способ измерения лица или группы лиц.

## Сила

```text
0–100%
```

Это opacity всей созданной группы.

```text
100% — полный рассчитанный эффект
50%  — половина видимого эффекта
```

ΔE в именах слоёв рассчитывается для полной коррекции 100%.

## Тени / света

```text
-100 … 0 … +100
```

```text
влево  → больший приоритет теням
0      → Auto
вправо → больший приоритет светам
```

Ползунок не осветляет и не затемняет изображение, он определяет какому тоновому диапазону будет отдан приоритет при коррекции. Затемнение или осветление всегда определяется эталоном.

Для обычной работы рекомендуется оставить `0`.

## Точность / защита

```text
-100 … 0 … +100
```

```text
Точность → более смелая коррекция
0        → Auto
Защита   → более осторожная коррекция
```

В сторону **Точность** алгоритм допускает более сильную коррекцию, если она действительно улучшает измерения.

В сторону **Защита** коррекция становится осторожнее и сильнее ограничивается влияние на соседние цвета.

Для большинства фотографий рекомендуется `0 — Auto`.

# Настройки

Под кнопкой с шестерёнкой доступны:

- **Папка пресетов**;
- **Размер анализа, px**;
- **Пропускать изображение, если лицо не найдено**;
- **Имя слоя**.

## Размер анализа

По умолчанию:

```text
1400 px
```

Для большинства портретов этого достаточно.

Если лицо очень маленькое в кадре, размер можно увеличить.

## Пропускать изображение, если лицо не найдено

Полезно при обработке серии через Photoshop Action.

Если опция включена, кадр без найденного лица просто пропускается.

# Что создаётся в Photoshop

Коррекция может состоять из трёх этапов:

```text
White Balance
Tone
Skin Match
```

White Balance и Tone создаются только тогда, когда действительно улучшают результат.

Типичная группа выглядит так:

```text
ΔE 7.1→4.4 — Face Color Match — preset
├─ Skin Match ΔE 5.8→4.4
├─ Tone ΔE 6.9→5.8 · ΔL* 8.1→6.7
└─ White Balance ΔE 7.1→6.9
```

Используются только стандартные корректирующие слои Photoshop:

- Curves;
- Color Lookup.

## White Balance

Исправляет общий цветовой сдвиг изображения.

## Tone

Исправляет светлоту кожи плавной Composite RGB Curve.

## Skin Match

Основной цветовой этап. Использует один **33×33×33 Color Lookup LUT** и автоматически согласует:

- остаточную светлоту;
- насыщенность;
- оттенок кожи.

Насыщенность и оттенок обрабатываются раздельно, чтобы коррекция оттенка не создавала лишнюю насыщенность.

---

# ΔE

Face Color Match использует **CIEDE2000 ΔE**.

Пример:

```text
ΔE 7.1→4.4 — Face Color Match — preset
```

Чем меньше итоговое значение, тем ближе измеренный цвет кожи к эталону.

Названия отдельных слоёв показывают вклад каждого этапа:

```text
White Balance ΔE 7.1→6.9
Tone ΔE 6.9→5.8 · ΔL* 8.1→6.7
Skin Match ΔE 5.8→4.4
```

`ΔL*` у Tone относится только к светлоте и поэтому не совпадает с общим ΔE.

---

# Photoshop Actions

Face Color Match поддерживает запись и воспроизведение через Photoshop Actions.

В Action сохраняются основные параметры коррекции и `preset_id`.

Если диалог Action включён, перед применением можно изменить параметры. Если выключен — используются записанные значения без открытия главного окна.

Для корректной работы Event ID скрипт должен быть установлен в `Photoshop\Presets\Scripts`.

# Важные особенности

- исходный документ не перезаписывается;
- анализ выполняется по временной JPEG-копии;
- временные файлы автоматически удаляются;
- вся коррекция создаётся как одна операция History;
- первый запуск после длительного простоя может быть немного медленнее, потому что локальный сервис запускается автоматически;
- для больших JPEG используется ускоренное уменьшенное декодирование.

# Если что-то не работает

## Face Color Match не появился в меню

Проверьте, что:

```text
Face Color Match.jsx
lib\
```

находятся именно в:

```text
Photoshop\Presets\Scripts
```

После копирования полностью перезапустите Photoshop.

## Скрипт не запускается

1. убедитесь, что установлен Python 3.11–3.14;
2. снова запустите `install.bat` в исходной распакованной папке;
3. после успешной установки заново скопируйте `Face Color Match.jsx` и всю папку `lib` в Photoshop;
4. перезапустите Photoshop.

## Лицо не найдено

Попробуйте:

- увеличить **Размер анализа**;
- убедиться, что лицо достаточно крупное и не сильно перекрыто;
- для группового фото использовать **Центральные лица (среднее)**.

## Результат слишком слабый

Попробуйте:

```text
Точность / защита → немного в сторону Точность
```

и убедитесь, что **Сила = 100%**.

## Результат слишком сильный

Попробуйте:

```text
Точность / защита → в сторону Защита
```

или уменьшите **Силу**.

## Цвет или насыщенность выглядят неправильно

В первую очередь проверьте:

- качество выбранного эталона;
- что и эталон, и текущий документ находятся в sRGB;
- не содержит ли эталон сильный локальный цветной рефлекс.
