# Face Color Match for Photoshop

Face Color Match помогает автоматически привести цвет и тон кожи на портрете к заранее сохранённому эталону.

Рабочий процесс простой: вы открываете фотографию в Photoshop, выбираете пресет с нужным эталоном кожи и запускаете коррекцию. Скрипт находит лицо, измеряет кожу в нескольких зонах и тональных диапазонах, сравнивает её с эталоном и создаёт обычные редактируемые корректирующие слои Photoshop.

Коррекция не заменяет изображение и не использует генеративные модели. На выходе остаются **Curves + один Color Lookup LUT**, объединённые в одну группу.

---

# Что умеет программа

- автоматически находит основное лицо на фотографии;
- измеряет кожу отдельно на лбу, щеках, носу и подбородке;
- сравнивает не только средний цвет, но и тени, средние тона и света;
- автоматически исправляет баланс белого, если это действительно улучшает совпадение;
- строит плавную тональную коррекцию без ломаных кривых;
- отдельно подбирает насыщенность и оттенок кожи;
- умеет заметно уменьшать как избыточную, так и недостаточную насыщенность;
- использует один итоговый **33×33×33 Skin Match LUT**;
- контролирует влияние LUT на цвета вне лица;
- автоматически отбрасывает или ослабляет небезопасные варианты коррекции;
- поддерживает многокадровые эталоны с усреднением нескольких фотографий;
- предупреждает, если новый эталон выглядит нестабильным;
- показывает измеренный ΔE до и после каждого этапа;
- объединяет создание всей коррекции в одну запись History Photoshop;
- поддерживает Photoshop Actions;
- автоматически запускает локальный Python-сервис и выключает его после 30 минут бездействия.

# Обязательное требование: sRGB

**Face Color Match рассчитан только на RGB-документы в профиле sRGB IEC61966-2.1.**

Перед созданием эталона и перед применением коррекции документ должен уже находиться в sRGB.

Для Adobe RGB, Display P3, ProPhoto RGB и других RGB-профилей корректность Lab-измерений и итогового LUT в текущей версии не гарантируется.

Если документ находится в другом профиле, используйте в Photoshop:

```text
Edit → Convert to Profile → sRGB IEC61966-2.1
```

Нужно именно **Convert to Profile**.

`Assign Profile` не является эквивалентной операцией и не должен использоваться вместо преобразования.

Face Color Match не преобразует профиль документа автоматически и не пытается исправлять неподдерживаемое цветовое пространство скрыто.

# Как выбирается лицо

Face Color Match автоматически ищет лица в кадре.

Если найдено несколько лиц, приоритет получает лицо, которое:

- занимает большую площадь;
- находится ближе к центру кадра.

Поэтому программа прежде всего рассчитана на портреты и кадры, где нужный человек является главным объектом.

Если в кадре несколько людей одинакового размера, лучше подготовить изображение так, чтобы нужное лицо было явно главным.

---

# Как измеряется кожа

После обнаружения лица Face Color Match нормализует его положение по landmarks YuNet и анализирует несколько устойчивых зон:

- левую щёку;
- правую щёку;
- лоб;
- нос;
- подбородок.

Глаза, рот и явно неподходящие пиксели по возможности исключаются из измерения.

В каждой пригодной зоне используются **11 тональных quantile** — от теней до светов.

Это позволяет сравнивать не один средний RGB-цвет, а распределение цвета кожи по всему рабочему тональному диапазону.

Случайные выбросы и локальные рефлексы получают меньший вес через robust reweighting.

Кнопка:

```text
+
```

создаёт новый эталон из текущего документа.

Имя по умолчанию берётся из имени открытого файла, но его можно изменить.

---

## Обновление пресета

Кнопка:

```text
↻
```

повторно измеряет текущий документ и предлагает два варианта:

```text
Добавить и усреднить
Заменить
```

### Добавить и усреднить

Текущая фотография становится ещё одним равноправным эталоном.

Соответствующие измерения кожи усредняются в **Lab**, отдельно по зонам и тональным quantile.

Например, если один пресет собран из трёх удачных фотографий одного человека при нужном освещении, случайные особенности отдельного кадра влияют на итоговый эталон меньше.

Если на одной фотографии какая-то зона лица не измерилась надёжно, отсутствующее измерение не разбавляет остальные зоны искусственно.

### Заменить

Накопленное усреднение удаляется, а текущий документ становится единственным эталоном пресета.

# Как выбирать хороший эталон

Лучший эталон — фотография, на которой:

- кожа нормально экспонирована;
- нет сильного цветного рефлекса только с одной стороны лица;
- нет выбитых светов на коже;
- лицо достаточно крупное;
- обе щеки имеют логичный, согласованный цвет;
- макияж, цветной свет и локальные отражения не искажают нужный результат.

Если Face Color Match обнаруживает подозрительный эталон, он **не запрещает его сохранять**, а показывает предупреждение.

Проверяются, в частности:

- количество надёжных зон кожи;
- количество пригодных skin pixels;
- качество skin mask;
- различие между левой и правой щекой;
- разброс измерений;
- близость каналов к клиппингу.

Для особенно важного пресета полезно использовать **несколько хороших эталонов через «Добавить и усреднить»**.

# Главное окно

## Пресет

Выбирает эталон, к которому будет приводиться кожа.

---

## Сила

Диапазон:

```text
0–100%
```

Это opacity всей созданной группы Face Color Match.

```text
100% — полный рассчитанный эффект
50%  — половина видимого эффекта
0%   — группа полностью выключена по opacity
```

Важно: ΔE в именах слоёв рассчитывается для **полной коррекции 100%**. Если после расчёта установить меньшую силу группы, указанное итоговое ΔE уже не является измерением фактически видимого результата.

---

## Тени / света

Диапазон:

```text
-100 … 0 … +100
```

```text
отрицательные значения → больший приоритет теням
0                      → Auto
положительные значения → больший приоритет светам
```

Ползунок не заставляет изображение осветляться или затемняться.

Направление коррекции всегда определяется эталоном. Ползунок только меняет, какой тональный диапазон должен сильнее влиять на плавную Tone-кривую.

Например, если эталон требует сделать тени светлее, движение к «Тени» сильнее поддержит именно это осветление. Если эталон требует их затемнить — будет усилено затемнение.

---

## Точность / защита

Диапазон:

```text
-100 … 0 … +100
```

```text
в сторону Точность → более смелая коррекция
0                  → Auto
в сторону Защита   → более осторожная коррекция
```

Этот ползунок влияет не только на формальные пороги проверки, но и на допустимую силу Skin Match.

В сторону **Точность** алгоритм может проверить Skin Match примерно до `120%` расчётной силы, но оставит его только при реальном улучшении измерений и прохождении обязательных защит.

В сторону **Защита** максимальная сила Skin Match постепенно уменьшается примерно до `60%`, а требования к влиянию на соседние цвета становятся строже.

Для обычной работы рекомендуется начать с:

```text
0 — Auto
```

# Как строится коррекция

Общая последовательность:

```text
Исходное изображение
        ↓
White Balance
        ↓
Tone
        ↓
Skin Match
```

White Balance и Tone создаются только тогда, когда проходят проверку пользы и безопасности.

Поэтому итоговая группа может содержать:

```text
Skin Match
```

или:

```text
Tone
Skin Match
```

или полный набор:

```text
White Balance
Tone
Skin Match
```

---

# White Balance

White Balance исправляет общий цветовой сдвиг изображения.

Он применяется только если:

- уменьшает измеренный ΔE кожи;
- большая часть контрольных измерений не ухудшается;
- коррекция не создаёт нежелательного ухудшения ключевых зон лица.

Photoshop получает обычный корректирующий слой Curves.

WB не используется автоматически только потому, что между кадрами есть разница: этап должен доказать реальную пользу.

---

# Tone

Tone отвечает за **светлоту** кожи.

Это одна плавная Composite RGB Curve.

Она:

- сохраняет чёрную и белую точки;
- не строит случайных независимых точек по каждому измерению;
- ограничивается по наклону;
- ограничивается по изменению наклона;
- отдельно контролирует глубокие тени;
- проверяется по фактическому уменьшению ΔE и ΔL*.

Ползунок **Тени / света** меняет приоритет разных частей этой Tone-кривой.

---

# Skin Match

Skin Match — основной цветовой этап.

Photoshop получает один:

```text
33×33×33 Color Lookup LUT
```

Внутренняя модель работает в Lab/LCh и объединяет:

```text
остаточный ΔL*(L*)
×
плавный chroma gain C* × g(L*)
+
плавный hue shift Δh(L*)
+
слабый локальный residual
```

После этого может быть рассчитана дополнительная внутренняя доводка, которая также запекается в тот же LUT.

Отдельного слоя Fine Tune нет.

---

# Насыщенность кожи

Насыщенность регулируется автоматически по эталону.

Face Color Match не использует простой глобальный Photoshop Saturation. Вместо этого сравнивается `C*` кожи в соответствующих тональных диапазонах.

Основная модель насыщенности работает как масштабирование:

```text
C* → C* × g(L*)
```

Это позволяет корректировать и явно перенасыщенные, и явно малонасыщенные фотографии.

Рабочий диапазон внутреннего chroma gain ограничен примерно:

```text
0.45× … 2.1×
```

То есть алгоритм имеет достаточно диапазона для заметной десатурации или насыщения, но не получает неограниченную свободу.

Локальные residual-коррекции в основном отвечают за оттенок. Их радиальная составляющая, способная дополнительно увеличить насыщенность, специально ограничена.

Дополнительная внутренняя доводка также не принимается, если начинает заметно ухудшать ошибку `C*`.

---

# Оттенок кожи

Оттенок и насыщенность рассматриваются раздельно.

Вместо попытки полностью описать цвет независимыми `a*` и `b*` используется:

```text
Chroma C*
Hue h
```

Поэтому скрипт может:

- изменить насыщенность, почти не вращая оттенок;
- скорректировать оттенок, не создавая лишнюю насыщенность;
- менять эти параметры плавно по светлоте кожи.

---

# Проверка безопасности Skin Match

При выборе силы LUT учитываются:

- уменьшение CIEDE2000 ΔE;
- отдельная остаточная ошибка chroma `C*`;
- доля измерений, которые не стали хуже;
- cross-validation по измерениям кожи;
- влияние LUT на реальные пиксели вокруг и вне области лица;
- итоговая работа именно дискретного LUT, который затем получает Photoshop.

Это важно: программа оценивает не только математическую непрерывную модель, но и фактический 33³ LUT.

---

# ΔE в именах слоёв

Face Color Match использует **CIEDE2000 ΔE**.

Пример итоговой группы:

```text
ΔE 7.1→4.4 — Face Color Match — образец 2008
```

Внутри могут быть:

```text
Skin Match ΔE 5.8→4.4
Tone ΔE 6.9→5.8 · ΔL* 8.1→6.7
White Balance ΔE 7.1→6.9
```

Эти значения образуют последовательную цепочку:

```text
исходник      7.1
White Balance 7.1 → 6.9
Tone          6.9 → 5.8
Skin Match    5.8 → 4.4
```

`ΔL*` у Tone — отдельная метрика только светлотной ошибки и поэтому не обязана численно совпадать с общим ΔE.

Итоговый ΔE является расчётом по тем же skin correspondences и фактическому LUT, но это не повторное измерение уже отрендеренного Photoshop-документа после создания слоёв.

При `Сила = 100%` это наиболее близкое представление ожидаемого результата.

---

# Photoshop Layers

Коррекция создаётся в отдельной группе.

Типичная структура:

```text
ΔE 7.1→4.4 — Face Color Match — preset
├─ Skin Match ΔE 5.8→4.4
├─ Tone ΔE 6.9→5.8 · ΔL* 8.1→6.7
└─ White Balance ΔE 7.1→6.9
```

Используются только стандартные Photoshop adjustment layers:

- Curves;
- Color Lookup.

Итоговый LUT встраивается непосредственно в Color Lookup layer вместе с RGB→RGB device-link ICC.

Временный `.cube` после создания слоя больше не нужен.

---

# History

Создание всей группы Face Color Match объединяется через `suspendHistory`.

Поэтому применение одной коррекции должно появляться в History Photoshop как **одна операция**, а не как последовательность из создания нескольких слоёв и их настройки.

---

# Photoshop Actions

Face Color Match поддерживает запись и воспроизведение через Photoshop Actions.

В Action сохраняются:

- `preset_id`;
- сила;
- Тени / света;
- Точность / защита;
- имя итоговой группы;
- поведение при отсутствии лица.

Сам путь к папке пресетов не записывается в Action. Используется текущая папка пресетов из настроек Face Color Match, а нужный эталон находится по стабильному `preset_id`.

При обычном запуске интерфейс показывается всегда.

При воспроизведении из Action используется стандартный переключатель диалога Photoshop:

- диалог включён — можно изменить параметры перед применением;
- диалог выключен — используются записанные параметры без открытия главного окна.

---

# Настройки программы

Файл настроек хранится непосредственно в:

```text
app.preferencesFolder\Face Color Match settings.json
```

Face Color Match использует только текущую схему настроек.

Старые схемы не переносятся и не объединяются автоматически. Если файл настроек имеет другую версию структуры, программа использует новые значения по умолчанию.

---

# Локальный Python-сервис

Отдельно запускать сервер не нужно.

При старте JSX:

1. проверяется локальный API;
2. если сервис уже запущен и соответствует версии JSX — он используется сразу;
3. если запущена другая версия — старый сервис останавливается;
4. JSX запускает `face-color-api.pyw`;
5. ожидает готовности OpenCV и NumPy;
6. начинает анализ.

Сервис слушает только локальный адрес:

```text
127.0.0.1
```

Используемые локальные порты:

```text
42971
42972
```

После примерно **30 минут бездействия** сервис автоматически завершает работу.

---

# Первый запуск после перезагрузки

Первый запуск Face Color Match после выключения Python-сервиса может занимать несколько секунд дольше, потому что нужно:

- запустить системный Python;
- импортировать NumPy;
- импортировать OpenCV;
- инициализировать детектор лиц.

В это время Photoshop показывает небольшое окно прогресса.

Последующие запуски выполняются быстрее, пока сервис остаётся активным.

---

# Скорость работы

Для больших JPEG Python старается не разворачивать исходную фотографию полностью без необходимости.

Используется уменьшенное JPEG-декодирование:

```text
1/2
1/4
1/8
```

после чего изображение точно приводится к выбранному размеру анализа.

Это особенно полезно для 40–60 МП фотографий.

Детекторы YuNet и Haar также кешируются внутри работающего Python-сервиса и не создаются заново при каждом кадре.

Сам Photoshop всё равно должен сохранить временную JPEG-копию текущего документа, поэтому скорость зависит также от сложности открытого PSD/PSB и производительности Photoshop.

---

# Временные файлы

Для обмена между Photoshop и Python временно используются:

- JPEG-копия документа;
- CUBE LUT;
- ICC device-link profile;
- служебные JSON-файлы запуска.

JPEG удаляется сразу после анализа.

CUBE и ICC удаляются после того, как Photoshop встроил их данные в Color Lookup layer.

При следующем запуске Python также очищает оставшиеся временные файлы от аварийно прерванной предыдущей сессии.

---

# Исходный документ

Face Color Match не должен:

- перезаписывать исходный файл;
- менять пиксели исходных слоёв;
- сводить документ;
- оставлять временное выделение;
- сохранять временный JPEG поверх исходника.

Для анализа используется **Save a Copy** во временную папку.

Если в документе было активное выделение, при создании корректирующих слоёв оно временно убирается и затем восстанавливается, чтобы случайно не превратиться в маску нового adjustment layer.

---

# Если лицо не найдено

Проверьте:

- достаточно ли крупное лицо;
- не перекрыто ли оно;
- не слишком ли сильный профиль/поворот головы;
- установлен ли YuNet;
- достаточно ли велик параметр **Размер анализа**.

Если YuNet не установлен, Face Color Match может перейти на Haar fallback, но его возможности заметно скромнее.

Для портрета с маленьким лицом попробуйте увеличить:

```text
Размер анализа
```

например с `1400` до `1800–2400`.

---

# Если результат слишком слабый

Сначала проверьте сам эталон.

Затем попробуйте:

```text
Точность / защита → немного в сторону Точность
```

Если проблема в конкретном тональном диапазоне:

```text
Тени / света → в нужную сторону
```

Также учитывайте **Силу** группы: при значении ниже 100% вся найденная коррекция дополнительно ослабляется уже в Photoshop.

---

# Если результат слишком сильный

Используйте:

```text
Точность / защита → в сторону Защита
```

или уменьшите:

```text
Сила
```

Разница между ними:

- **Защита** влияет на сам выбор безопасной коррекции;
- **Сила** просто уменьшает opacity уже найденной группы.

---

# Если насыщенность всё ещё кажется неправильной

Face Color Match измеряет насыщенность относительно выбранного эталона.

Если ручное изменение Saturation заметно уменьшает ΔE при повторном анализе, в первую очередь проверьте:

- действительно ли текущий пресет содержит нужную насыщенность кожи;
- нет ли в эталоне сильного цветного света или рефлекса;
- не собран ли усреднённый пресет из слишком разных по свету фотографий;
- находится ли и эталон, и текущий документ именно в sRGB.

Для критичных пресетов лучше добавить несколько согласованных эталонов через:

```text
↻ → Добавить и усреднить
```

---

# Если Python не запускается

Сначала снова запустите:

```text
install.bat
```

Убедитесь, что Windows видит Python Launcher:

```text
py --version
```

И хотя бы одну поддерживаемую версию:

```text
py -3.11 --version
py -3.12 --version
py -3.13 --version
py -3.14 --version
```

Достаточно, чтобы работала одна из них.

# Журнал

Во время работы или после аварийно завершившейся сессии журнал можно найти во временной папке Windows:

```text
%TEMP%\face-color-match.log
```

Он полезен, если:

- Python не запускается;
- OpenCV не импортируется;
- YuNet не инициализируется;
- локальный API не отвечает;
- анализ завершается неожиданной ошибкой.

После нормального завершения сервиса служебные временные файлы и журнал могут быть очищены автоматически.

---

# Главное

Обычный рабочий процесс выглядит так:

1. установить системный **Python 3.11–3.14**;
2. один раз запустить `install.bat`;
3. убедиться, что документ находится в **RGB / sRGB IEC61966-2.1**;
4. открыть хороший эталон и создать пресет кнопкой `+`;
5. при необходимости добавить ещё хорошие эталоны через `↻ → Добавить и усреднить`;
6. открыть фотографию для коррекции;
7. выбрать пресет;
8. оставить **Тени / света = 0** и **Точность / защита = 0** как отправную точку;
9. нажать **Применить**;
10. при необходимости скорректировать настройки и повторить.

Для большинства фотографий разумная отправная точка:

```text
Размер анализа:       1400 px
Сила:                  100%
Тени / света:          0
Точность / защита:     0
```

Главное условие предсказуемой работы — **хороший sRGB-эталон**. Если эталон стабилен, Face Color Match автоматически согласует светлоту, насыщенность и оттенок кожи, сохраняя результат в обычных редактируемых слоях Photoshop.
